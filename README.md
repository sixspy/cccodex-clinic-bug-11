# cc-clinic-lab · 临床试验访视采集台

数据工程产品线基线。题号前缀 `clinic-*`，默认端口 **7600**。

## 技术栈

- 后端：CherryPy + SQLite
- 前端：原生 JS SPA（顶栏薄荷绿丝带导航）
- 会话：itsdangerous 签名 Cookie
- 测试：pytest + httpx（依赖已列入 requirements）

## 登录

- 地址：`http://127.0.0.1:7600/login`
- 账号：`admin` / `123456`

## 页面

| 页面 | 能力 |
|------|------|
| 试验中心 | 中心登记、启停/观察、配额、方案版本生效 |
| 访视批次 | 开批、模拟抓取、追加访视行、合格入库、收齐/关闭 |
| 字段质控 | 按批/全量扫描、发现关闭/重开 |
| 缺口补采 | 排队、执行成功/失败、失败重试 |
| 访视对账 | 缺口/发现/补采对照、中心矩阵、审计 |
| 台参数 | 设置读写 |

## 主链

中心 → 访视批次抓取 → 质控发现 → 缺口补采 → 对账报告；设置与审计贯穿写操作。

## 协议切流（甲路：物化包 + 切流账册）

- 切流徽标**只由业务库 `proto_cut_landing` 唯一落点行驱动**：无落点行时徽标恒为“协议版旧”，读轨停 `old_track`，任何皮面/半修/对账动作都点不亮。
- 未钉定前，访视批次「模拟抓取」一律 **409 驳回**（不得交卷/收签/验收），业务库不增行。
- 钉定在「试验中心」页发起：计算当刻业务指纹、写物化包（`meta` 的 `proto_cut_pack_*`，无 decoy）、插入唯一落点行，读轨切到 `cutover_book` 且拒回刷。
- 落点行 `CHECK(id=1)` 物理唯一 + `BEGIN IMMEDIATE` 事务：双边仓管争写时只有一方成功，另一方 409，无双写覆盖。
- 乙路（双写两轨/只读历史面）已拆除，`/api/proto_cut/dual` 返回 404；台参数页仅保留只读复核，钉定操作不与中心页并存。

## 本地

